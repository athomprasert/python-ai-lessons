What's unique about Request Compression: MCP Payload Optimization already handles tool result compression. What Request Compression uniquely covers is the conversation history — the system prompt, user messages, and assistant replies that the agent runtime re-sends on every turn. Each is billed again by the provider each time it's replayed. The policy applies Minify (collapse whitespace), Remove Nulls/Empty Values, and TOON to every string in the request body — including instructions, all message texts, and anything not already handled upstream.
