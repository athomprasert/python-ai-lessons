Extending the Loop: Automatic Containment Not a built-in feature — a build-your-own layer
Flag Fires
Rogue Agent Detection raises a flag (e.g. PII Leak) and can push an alert notification.
→
Webhook / Notification
Alert routes to your own automation instead of only a human dashboard.
→
API / Terraform Call
Your automation appends the agent's ID to the Kill Switch's Killed Agent IDs via the API Manager API.
→
Agent Blocked — No Wait
Containment happens without waiting on a human click, for the anomaly types you trust enough to automate.
MuleSoft's documentation is explicit that quarantine requires human review by design — this automated path is an architecture you would build on top of the exposed policy configuration and alerting, not a supported out-of-the-box mode. Reserve it for your highest-confidence signals and keep lower-confidence or Custom-rule flags on the manual review path.
